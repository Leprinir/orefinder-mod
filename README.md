# OreFinder Mod 🧭

**Minecraft Forge 1.20.1+ мод** — предмет-компас для поиска руд в режиме выживания.

## Концепция

Предмет **OreFinder** — карманный помощник шахтёра. Это улучшаемый инструмент, который:
- Показывает направление и расстояние до ближайшей руды
- Улучшается по мере прокачки (больше радиус, больше видов руд)
- Доступен с ранней игры (крафтится из базовых материалов)

## Прогресия предмета

| Уровень | Название | Радиус | Руды | Крафт |
|---------|----------|--------|------|-------|
| 1 | Stone OreFinder | 8 блоков | Уголь, Медь | Камень + Стр.Палка + Компас |
| 2 | Iron OreFinder | 16 блоков | +Железо, Золото | Предыдущий + Железный слиток |
| 3 | Gold OreFinder | 32 блока | +Лазурит, Редстоун, Медь | Предыдущий + Золотой слиток |
| 4 | Diamond OreFinder | 64 блока | +Изумруд, Даймонд, Незерит | Предыдущий + Даймонд |
| 5 | Emerald Master | ∞ блоков | Все руды | Даймондовый + Изумруд |

## Механика

- **ПКМ** — активировать сканер (звук + частицы)
- **ЛКМ** — деактивировать
- **Shift+ПКМ** — переключить режим (ближайшая / по типу)
- На экране: стрелка-компас указывает на ближайшую руду + HUD с расстоянием
- Чем ближе — тем ярче частицы и выше частота звука

## Сборка

```bash
./gradlew build
# JAR будет в build/libs/
```
